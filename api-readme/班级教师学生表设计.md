# 班级、教师、学生 数据表设计

## 现有用户结构

当前 `user` 表结构：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | VARCHAR | 用户唯一标识（主键） |
| password | VARCHAR | 加密密码 |
| name | VARCHAR | 显示名称 |
| date | VARCHAR | 创建日期 |

> 现有用户表未区分角色，所有用户身份统一存储。本次设计在此基础上扩展角色体系，通过外键关联 user 表，避免破坏现有结构。

---

## 设计思路

- **不修改现有 user 表**，通过 `role` 字段区分用户类型
- 教师、学生均关联到 user 表（一对一），共享认证体系
- 班级作为独立实体，教师与学生通过中间表与班级关联
- 保持与现有代码风格一致：MyBatis 注解 + POJO Model
- 主键使用 VARCHAR，时间字段使用 VARCHAR，与现有约定一致

---

## 数据表设计

### 1. 班级表 `class`

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| class_id | VARCHAR | PRIMARY KEY | 班级唯一标识 |
| class_name | VARCHAR | NOT NULL | 班级名称 |
| description | VARCHAR | | 班级描述 |
| create_time | VARCHAR | NOT NULL | 创建时间 |
| update_time | VARCHAR | | 最后更新时间 |
| display | INT | DEFAULT 0 | 是否展示（0展示 1隐藏） |

创建班级需要用户的vip等级为10，等级是：getQuotaAndRank(String id)方法返回的rank

```sql
CREATE TABLE `class` (
    `class_id` VARCHAR(64) PRIMARY KEY,
    `class_name` VARCHAR(128) NOT NULL,
    `description` VARCHAR(512),
    `create_time` VARCHAR(32) NOT NULL,
    `update_time` VARCHAR(32),
    `display` INT DEFAULT 0
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 2. 教师表 `teacher`

上传的时候要传用户id和被创建的教师的id
创建教师表需要用户的vip等级为12，等级是：getQuotaAndRank(String id)方法返回的rank
创建教师表的时候按照上传上来的教师id创建vip表里的数据，给每年2亿额度，rank为10的vip授权，一年一年的授权（每一条数据是年分的）一共授权时间是12年

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| teacher_id | VARCHAR | PRIMARY KEY | 教师唯一标识 |
| usr_id | VARCHAR | FOREIGN KEY -> user.id | 关联的用户账号 |
| title | VARCHAR | | 职称（如：教授、讲师） |
| create_time | VARCHAR | NOT NULL | 创建时间 |

```sql
CREATE TABLE `teacher` (
    `teacher_id` VARCHAR(64) PRIMARY KEY,
    `usr_id` VARCHAR(64) NOT NULL,
    `title` VARCHAR(64),
    `create_time` VARCHAR(32) NOT NULL,
    FOREIGN KEY (`usr_id`) REFERENCES `user`(`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 3. 学生表 `student`

上传的时候要传用户id和被创建的学生的id和班级
创建学生表需要用户的vip等级为10，等级是：getQuotaAndRank(String id)方法返回的rank
创建学生表的时候按照上传上来的学生id创建vip表里的数据，每个月给1140万额度，rank为5的vip授权，授权时间是4年。

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| student_id | VARCHAR | PRIMARY KEY | 学生唯一标识 |
| usr_id | VARCHAR | FOREIGN KEY -> user.id | 关联的用户账号 |
| student_no | VARCHAR | | 学号 |
| create_time | VARCHAR | NOT NULL | 创建时间 |

```sql
CREATE TABLE `student` (
    `student_id` VARCHAR(64) PRIMARY KEY,
    `usr_id` VARCHAR(64) NOT NULL,
    `student_no` VARCHAR(64),
    `create_time` VARCHAR(32) NOT NULL,
    FOREIGN KEY (`usr_id`) REFERENCES `user`(`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 4. 班级-教师关联表 `class_teacher`

教师创建班级的时候需要自动加入班级，暂时不提供后续的管理服务，只是在创建班级的时候自动加入班级

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | VARCHAR | PRIMARY KEY | 记录标识 |
| class_id | VARCHAR | FOREIGN KEY -> class.class_id | 班级 |
| teacher_id | VARCHAR | FOREIGN KEY -> teacher.teacher_id | 教师 |
| join_time | VARCHAR | NOT NULL | 关联时间 |

```sql
CREATE TABLE `class_teacher` (
    `id` VARCHAR(64) PRIMARY KEY,
    `class_id` VARCHAR(64) NOT NULL,
    `teacher_id` VARCHAR(64) NOT NULL,
    `join_time` VARCHAR(32) NOT NULL,
    FOREIGN KEY (`class_id`) REFERENCES `class`(`class_id`),
    FOREIGN KEY (`teacher_id`) REFERENCES `teacher`(`teacher_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 5. 班级-学生关联表 `class_student`

由教师决定谁加入班级，教师可以添加、删除、修改班级成员的角色

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | VARCHAR | PRIMARY KEY | 记录标识 |
| class_id | VARCHAR | FOREIGN KEY -> class.class_id | 班级 |
| student_id | VARCHAR | FOREIGN KEY -> student.student_id | 学生 |
| join_time | VARCHAR | NOT NULL | 加入时间 |
| role | VARCHAR | DEFAULT 'member' | 角色（member班长/monitor课代表/普通成员） |

```sql
CREATE TABLE `class_student` (
    `id` VARCHAR(64) PRIMARY KEY,
    `class_id` VARCHAR(64) NOT NULL,
    `student_id` VARCHAR(64) NOT NULL,
    `join_time` VARCHAR(32) NOT NULL,
    `role` VARCHAR(32) DEFAULT 'member',
    FOREIGN KEY (`class_id`) REFERENCES `class`(`class_id`),
    FOREIGN KEY (`student_id`) REFERENCES `student`(`student_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

## ER 关系

```
user (1) ── (0..1) teacher
user (1) ── (0..1) student

class (1) ── (N) class_teacher ── (N) teacher
class (1) ── (N) class_student ── (N) student
```

一个用户可以是教师、学生，或两者都不是（保持现有兼容）。
一个教师可以管理多个班级，一个班级可以有多名教师。
一个学生可以加入多个班级，一个班级可以有多名学生。
